primeiros passos na tecnologia...

Aprendi a montar meus primeiros blocos de código e entendi como a lógica por trás das telas funciona de verdade. É inacreditável perceber como uns poucos comandos ganham vida na tela de forma tão rápida.

meu primeiro projeto...

Se você me dissesse há uma semana que eu seria capaz de programar um jogo, eu não acreditaria. Mas hoje rolou um marco gigante no meu aprendizado tech: finalizei meu primeiro projeto oficial usando o Scratch! O desafio parece simples, mas para mim foi épico. Criei um gato interativo que desvia de obstáculos enquanto soma pontos na tela. O mais legal foi entender a lógica por trás de tudo. Em vez de decorar códigos difíceis, fui encaixando blocos coloridos como se fosse um quebra-cabeça digital. Movimentação: Programei as setas do teclado para fazer o personagem andar. Pontuação: Criei uma variável para contar cada desvio certo. Sons e efeitos: Adicionei um barulhinho toda vez que ele consegue marcar um ponto! Ver aquele monte de blocos virar um jogo de verdade me deu um orgulho gigante. É só o começo, mas já estou cheio de ideias para os próximos projetos.
